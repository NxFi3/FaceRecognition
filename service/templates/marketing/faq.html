{% translate "Can the application work without internet?" %}

{% translate "Yes. Initial activation is online; the signed license then works offline until its expiration. A network failure alone does not invalidate a valid license. Renewal and updated status require an online connection." %}

{% translate "What happens when the subscription expires?" %}

{% translate "Operational features stop, but school data is not deleted. Export and local recovery remain available. Normal use resumes after renewal is approved and a new license is received." %}

{% translate "How is payment verified?" %}

{% translate "Payments currently follow the order's manual instructions. An authorized operator must verify the transfer against the banking source. An order, payment claim or browser redirect alone never activates a subscription." %}

{% translate "Does a trial activate immediately?" %}

{% translate "No. The public demo uses synthetic data. An installation trial, if published, requires authorized approval and assessment." %}

{% translate "Is face information sent to the cloud?" %}

{% translate "Not for daily processing. Processing runs on the school computer. Cloud backup is entirely optional, and new backups are encrypted with the school key before upload. Cloud face processing is not offered in the current product." %}

{% translate "What if the recovery key is lost?" %}

{% translate "The school holds its recovery key; the server does not. If every copy is lost, the vendor cannot recover a new encrypted backup. Keep two protected copies in separate places." %}

{% translate "What does archiving a student do?" %}

{% translate "Archiving in this pilot classifies the capacity roster. It does not automatically delete records or face templates, or disable recognition or attendance decisions for that student. Reactivation requires available capacity." %}

{% translate "Does reducing plan capacity delete data?" %}

{% translate "No. Reducing capacity does not erase historical records. New student enrollment or activation is limited until capacity is available. Support reviews changes to an active plan." %}

{% translate "Does device revocation immediately affect an offline installation?" %}

{% translate "No. A fully offline device learns of signed revocation on its next successful synchronization. Without connecting it may operate until its previous license expires. Long offline validity and immediate remote revocation cannot both be guaranteed." %}

{% translate "Is a particular recognition accuracy or speed guaranteed?" %}

{% translate "No. Lighting, movement routes, enrollment quality, cameras and hardware matter. Testing in the real environment and administrator review are essential. Results from one system do not guarantee all installations." %}

{% translate "What permission is required to use student information?" %}

{% translate "The school must arrange permissions, consent and notices under applicable rules. Specify data categories, purpose, retention and the responsible contact. Obtain legal review of deployment terms before a pilot." %}

{% translate "Is your question school-specific?" %}

{% translate "Submit technical and contractual requests without sensitive student information." %}
